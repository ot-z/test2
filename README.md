# 刷题学习助手（quiz-assistant）

长期备战蓝桥杯一类算法竞赛的个人刷题学习助手：自动安排每日新题与复习题、沉淀思路笔记、按需导出复盘文档，并可接入 DeepSeek 做题目分析与代码诊断。

> **当前状态：v1.2.0 已交付（新增洛谷公开题面批量下载 FR-30）。**
> v1.0.0 落地 M1–M4 全部功能（28 条 FR）；v1.1.0 修正蓝桥杯题号/链接错误并新增「配置驱动的自动题目录入与扫描采集」（FR-29）；v1.1.1 修复计划重建问题；
> v1.2.0 按你的要求开放**洛谷公开题面的本地缓存**：按递增题号下载题面，自动设置标签、知识点、难度，并生成 Markdown 文件（详见第九节）。
> **桌面程序打包是下一步**：等你体验确认没有问题后，再把这套本地服务封装成双击即开的桌面窗口应用。本轮不做打包。

## 一、最快启动

**Windows 直接双击根目录的 `启动.bat`** 即可。脚本会：

1. 首次运行自动创建 `.venv` 并安装 `requirements.txt`；
2. 选择 `127.0.0.1:8765` 起的第一个空闲端口；
3. 自动执行 Alembic 迁移 → 装配内置知识点树/大纲/起始题库 → 补齐今日计划 → 每日备份；
4. 启动服务并自动打开浏览器。

命令行等价方式：

```bash
python run.py
# 或
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

关闭：在窗口按 `Ctrl+C`，或直接关闭窗口。访问 `http://127.0.0.1:8765/`。

> 核心刷题闭环（计划、打卡、笔记、历史、导出）**完全离线可用**；只有「数据源同步」和「AI 分析」需要联网。

### 题号链接规则（唯一配置入口）

所有「题号 → 原题链接」的规则都在 `config/link_rules.yaml`，新增站点或修改链接格式**只改 YAML，不用改代码**；`config/link_rules.custom.yaml` 是用户覆盖层，可在「题号采集 → 编辑规则」里直接改，保存后热加载、纳入 git 可回退。

- **蓝桥云课**：题号是官方题库列表页的「编号」，链接 `https://www.lanqiao.cn/problems/{编号}/learning/`。**A+B 问题【OJ 示例题目】= 254，不是 1**；v1.0.0 起始题库里虚构的 1~6 已修正为 254 / 600 / 602 / 192 / 498 / 1447。旧练习系统 `T1`、`BEGIN-1` 走 legacy 变体 `lx.lanqiao.cn/problem.page?gpid=...`。
- **洛谷**：`https://www.luogu.com.cn/problem/{题号}`，题号前缀 P（主题库，纯数字自动补 P）/ B / CF / SP / AT / UVA / U / T；蓝桥杯历年真题在洛谷也是 P 开头（如 P8649、P16232）。
- 扫描输入示例：`254 A+B 问题`、`LQ605 年号字串`、`P1001-P1005`（连续展开）、`https://www.luogu.com.cn/problem/P8649 k 倍区间`。「题库体检」会列出题号不合规、链接不匹配、旧种子编号，「预览修复 / 执行修复」按规则批量纠正。
- 相关接口：`/api/link-rules`（规则清单/编辑）、`/preview`、`/collect`、`/audit`、`/repair`、`/derive`。**这些接口全部是本地字符串推导，不发起任何外部网络请求**。

### 计划生成与重建（v1.1.1）

首页右上角的 **「重建未来 30 天计划」** 走 `POST /api/plan/regenerate?days=30`，与旧的 `/api/plan/generate` 语义不同：

- 窗口**从今天起算** 30 天（旧接口从配置的 `start_date` 起算，改过起始日期会只覆盖到过去）；
- 已有日期**只补齐缺口**（按当前 `new_per_day` / `review_per_day` 补足任务），不删除、不改任何已有任务，学习记录、笔记、已完成状态全部保留；连续点两次不会重复添加；
- 「只补今天」走同一接口的 `days=1`；
- **在「设置」改完计划参数后，必须回首页点一次「重建未来计划」**，新参数才会对未来日期生效（TC-04 参数不回溯：历史计划快照保持不变）；
- 题单耗尽时按 FR-10 只把日期标记为「题单不足」，**不从题库随机补题**。页面会给出容量估算（题库总数 / 剩余 / 按当前每日题量可覆盖天数），并提供「从题库补充题单并重建」按钮，把尚未排过计划的题补入已确认题单；也可到「题号采集」录入更多题目，或调低「每日新题」。

> 容量提示：当前内置题库 89 道，按每日 3 道新题无法连续覆盖 30 天（约需 90 道）。若想 30 天不断档，建议把「每日新题」设为 1，或先扩充题库。

## 九、洛谷题面批量下载（FR-30，v1.2.0）

### 9.1 它做什么

按 `P1001 → P1002 → …` 递增题号读取**公开题目页自带的题面数据**，每题自动完成：

| 写入位置 | 内容 |
| --- | --- |
| `problems` | 标题、原题链接、洛谷原始难度 + 项目 1–5 档难度、全部外部标签、通过数、`sync_status=crawled` |
| `problem_knowledge` | 由 `config/luogu.yaml` 的标签 → 知识点树映射自动关联（`confidence=mapped`，不覆盖人工标注） |
| `problem_snapshots` | 完整 Markdown 题面（背景 / 描述 / 输入输出格式 / 样例 / 数据范围 / 限制），带来源与采集时间、内容不变则不重复写 |
| `exports/luogu/*.md` | 同内容的本地文件，可用任意编辑器 / Obsidian 打开 |
| `exports/luogu/index.csv` | 全量索引：题号、标题、难度、标签、链接、本地文件路径 |

难度名称以站点 `/_lfe/config` 的 `ProblemDifficulty`（当前 0–8 共 9 档）为准，自动同步并缓存；项目 5 档的换算在 `config/luogu.yaml` 里可改。标签字典来自 `/_lfe/tags`，算法类标签才参与知识点归一，年份 / 来源 / 地区等只作为检索标签保存。

### 9.2 三种用法

**① 网页（小批量，单次 ≤ 60 题）**：「题号采集」页底部「洛谷题面下载」面板 → 填起止题号 → 预览 → 开始下载；也可点「补录已录题」只给题库里已有洛谷题补题面。

**② 命令行 / 一键全量（推荐，可中断续跑）**：Windows 下直接双击根目录 **`下载全部洛谷题面.bat`**（等价于 `--all`），先拉题库清单再逐题抓题面；`Ctrl+C` 中断后再次双击自动续跑。**在 PowerShell 里必须写成 `.\下载全部洛谷题面.bat`**——PowerShell 默认不从当前目录加载命令，直接输文件名会报 `CommandNotFoundException`。bat 也支持透传参数，例如 `.\下载全部洛谷题面.bat --only-status`、`.\下载全部洛谷题面.bat --all --max-items 500`、`.\下载全部洛谷题面.bat --start 1001 --end 1100`；不带参数才是全量。常用命令：

```bash
# 抓 P1001~P1100（重复运行同一命令即从断点续跑）
.venv\Scripts\python.exe scripts\fetch_luogu.py --start 1001 --end 1100

# 只给题库里已录入的洛谷题补题面 / 标签 / 知识点 / 难度
.venv\Scripts\python.exe scripts\fetch_luogu.py --existing

# 全量：先拉公开题库清单（当前约 1.67 万题，约 335 页），再按精确题号逐题抓题面
.venv\Scripts\python.exe scripts\fetch_luogu.py --all

# 只看进度 / 只预览不联网 / 重新拉清单 / 重抓某段
.venv\Scripts\python.exe scripts\fetch_luogu.py --only-status
.venv\Scripts\python.exe scripts\fetch_luogu.py --start 1001 --end 1100 --dry-run
.venv\Scripts\python.exe scripts\fetch_luogu.py --all --refresh-catalog
.venv\Scripts\python.exe scripts\fetch_luogu.py --start 1001 --end 1100 --refresh

# 只重建索引（不联网）：关闭被 Excel 占用的 index.csv 后把索引合并回去
.venv\Scripts\python.exe scripts\fetch_luogu.py --rebuild-index
```

其它参数：`--interval 2`（放慢）、`--max-items 500`（分批，配合 `--all` 即每次续跑 500 题）、`--max-missing 300`（连续多少个空题号后停）、`--force`（覆盖人工编辑过的元信息）、`--no-files`（只写库）、`--retry-missing`（重试之前判为不存在的题号）。

> 索引文件 `index.csv` 常被 Excel / 编辑器打开而独占。重建索引遇到占用时会自动**覆盖写到固定的 `index-new.csv`** 并在输出中提示，**题面与题库数据不受影响**；关闭该文件后运行一次 `--rebuild-index` 即可写回主索引。备用索引固定一个文件，不会随分批采集累积，也不会删除任何本地文件。

**③ REST**：`GET /api/luogu/status`（进度与统计）、`POST /api/luogu/fetch`（`{start, end, interval, mode, dry_run}`）。

### 9.3 时间成本与断点

默认 **1.2 秒/请求**。全量约 `335 页清单 + 16717 题 ≈ 17052 次请求`，按 1.2 秒约 **5.7 小时**，建议分批（例如每次 500 题）或夜间运行。进度保存在 `data/luogu_fetch_state.json`，每 10 题落盘一次；随时 `Ctrl+C`，下次运行自动跳过已完成的题号，题面内容不变不会重复产生快照。连续 120 个题号不存在会判定到题库末尾，连续 6 次请求失败或遇 429 会自动退避 / 停止，不会持续给站点加压。

### 9.4 合规（重要）

只读取浏览器打开该页面就能看到的公开题面数据；不登录、不复用账号 Cookie、不处理验证码或 JS 挑战、不抓需权限题目与题解、不批量下载图片附件。CDN 下发的匿名访问 cookie 由 HTTP 客户端按浏览器常规行为自动保存。题面**版权归洛谷及出题人所有**，这里仅作你个人的本地学习缓存，不进入任何导出文档，请勿二次分发或用于公开服务。若站点改版，优先调 `config/luogu.yaml`；若页面 JSON 结构变化，需要同步更新 `app/services/luogu.py` 的解析逻辑。

## 十、题目工作台（FR-31）

在「今日任务」点「题目工作台」，或在「题库目录」点题目标题 / 「工作台」按钮，会弹出一个可拖拽、可缩放、可最大化的悬浮窗口；标题栏的「独立窗口」还能把它开成单独浏览器窗口（`/workbench/<题目ID>`）。五个面板：

| 面板 | 内容 |
| --- | --- |
| 题面 | 本地题面快照（Markdown 渲染，可切换版本）、元信息、知识点、标签、原题链接；无快照时可自行粘贴保存 |
| 代码 | 语言切换、带行号的编辑器、Tab 缩进、Ctrl/⌘+S 保存、复制、一键送去 AI 诊断 |
| AI 分析 | 思路引导 / 代码诊断（SSE 流式、可停止）、历史分析记录、一键存为思路笔记 |
| 学习记录 | 该题历史练习记录 + 登记本次练习（自动带上当前代码） |
| 思路笔记 | 考察知识点、最近一次 AI 思路摘要、自己的 Markdown 笔记 |

代码草稿存在 `code_drafts` 表，一题一份、覆盖式保存，**仅本地、不参与导出**。AI 分析复用既有 DeepSeek 配置并自动记入 `ai_calls`；点击时明确提示「题面 / 代码会离开本机，发送给你配置的 DeepSeek」，由你主动确认使用边界。

接口：`GET /api/problems/{id}/workbench`（一次取齐五个面板）、`PUT /api/problems/{id}/code`（保存草稿）。

## 十一、个人能力画像（FR-32）

左侧新增「能力画像」页，给每个知识点标 0–5 的掌握程度：

`0 未接触（新知识） · 1 听说过但不会用 · 2 能看懂题解 · 3 能独立做基础题 · 4 熟练能变形 · 5 能讲解与变通`

未评估的知识点按 2 处理；支持搜索、批量填入、只填未评估、备注，以及全局规则（是否启用、允许比当前水平高出的难度档数、每天建议接触几道新知识题）。

三个生效点：

1. **计划匹配**：候选题按能力适配分稳定重排——偏难、含新知识的题往后排，先做巩固题。**只调整顺序，不增减任务数量、不改复习关系**；没有任何掌握度记录时完全保持原有计划逻辑（TC-01～TC-04 不受影响）。
2. **AI 分析匹配**：把画像写进 system prompt，要求讲解深度与自评水平一致、不跳步、不默认已懂高级术语。凡涉及掌握度 ≤ 1 的知识点，**首次出现必须用「【新知识】知识点名」标记**，并详细说明大白话定义、最小直观例子、为什么本题需要、前置知识与最小可用模板、与已掌握知识的联系；超出水平太多时先列「建议先补」。前端会把【新知识】高亮显示。
3. **工作台提示**：题面面板顶部显示该题的能力匹配结论、我的水平 / 题目难度、新知识 / 薄弱 / 已掌握知识点清单与学习建议。

接口：`GET /api/ability/profile`、`PUT /api/ability/config`、`PUT /api/ability/levels`、`GET /api/ability/match/{problem_id}`；工作台详情接口内嵌 `ability` 字段。

> 数据库升级由 Alembic 自动完成：`9c1e4b7a2d35`（code_drafts）→ `b3f72c9e4a18`（knowledge_mastery），可 `alembic downgrade` 回退。升级前的完整备份在 `backups/`。
