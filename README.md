# 刷题学习助手（quiz-assistant）

长期备战蓝桥杯一类算法竞赛的个人刷题学习助手：自动安排每日新题与复习题、沉淀思路笔记、按需导出复盘文档，并可接入 DeepSeek 做题目分析与代码诊断。

> **当前状态：v1.1.0 已交付，等待你实际体验确认。**
> v1.0.0 按需求文档落地 M1–M4 全部功能（28 条 FR）；v1.1.0 修正蓝桥杯题号/链接错误并新增「配置驱动的自动题目录入与扫描采集」（FR-29）。
> **桌面程序打包是下一步**：等你体验确认没有问题后，再把这套本地服务封装成双击即开的桌面窗口应用。本轮不做打包。

## 一、最快启动

**Windows 直接双击根目录的 `启动.bat`** 即可。脚本会：

1. 首次运行自动创建 `.venv` 并安装 `requirements.txt`；
2. 选择 `127.0.0.1:8765` 起的第一个空闲端口；
3. 自动执行 Alembic 迁移 → 装配内置知识点树/大纲/起始题库 → 补齐今日计划 → 每日备份；
4. 启动服务并自动打开浏览器。

命令行等价方式：

```bash
python run.py
# 或
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

关闭：在窗口按 `Ctrl+C`，或直接关闭窗口。访问 `http://127.0.0.1:8765/`。

> 核心刷题闭环（计划、打卡、笔记、历史、导出）**完全离线可用**；只有「数据源同步」和「AI 分析」需要联网。

### 题号链接规则（唯一配置入口）

所有「题号 → 原题链接」的规则都在 `config/link_rules.yaml`，新增站点或修改链接格式**只改 YAML，不用改代码**；`config/link_rules.custom.yaml` 是用户覆盖层，可在「题号采集 → 编辑规则」里直接改，保存后热加载、纳入 git 可回退。

- **蓝桥云课**：题号是官方题库列表页的「编号」，链接 `https://www.lanqiao.cn/problems/{编号}/learning/`。**A+B 问题【OJ 示例题目】= 254，不是 1**；v1.0.0 起始题库里虚构的 1~6 已修正为 254 / 600 / 602 / 192 / 498 / 1447。旧练习系统 `T1`、`BEGIN-1` 走 legacy 变体 `lx.lanqiao.cn/problem.page?gpid=...`。
- **洛谷**：`https://www.luogu.com.cn/problem/{题号}`，题号前缀 P（主题库，纯数字自动补 P）/ B / CF / SP / AT / UVA / U / T；蓝桥杯历年真题在洛谷也是 P 开头（如 P8649、P16232）。
- 扫描输入示例：`254 A+B 问题`、`LQ605 年号字串`、`P1001-P1005`（连续展开）、`https://www.luogu.com.cn/problem/P8649 k 倍区间`。「题库体检」会列出题号不合规、链接不匹配、旧种子编号，「预览修复 / 执行修复」按规则批量纠正。
- 相关接口：`/api/link-rules`（规则清单/编辑）、`/preview`、`/collect`、`/audit`、`/repair`、`/derive`。**这些接口全部是本地字符串推导，不发起任何外部网络请求**。

## 五、版本管理与回退

| 项 | 约定 |
| --- | --- |
| 分支 | `main` 可运行稳定版；`dev` 日常开发 |
| 标签 | `v0.1.0-docs`（文档基线）、`v1.0.0-rc1`（首个可运行候选）、`v1.0.0`（完整版本交付）、`v1.1.0`（题号规则与采集） |
| 提交 | Conventional Commits，一事一提交，便于 `git revert` |
| 数据库 | 所有 schema 变更走 Alembic；`data/`、`exports/`、`backups/` 不入库，另有每日备份与 JSON 快照 |

回退流程：

```bash
git tag                                  # 查看可回退版本
git checkout v1.0.0                      # 验证某个历史版本
.venv\Scripts\alembic.exe downgrade base # 如需对齐 schema
.venv\Scripts\alembic.exe upgrade head   # 再升级回来
git switch main
```

> 代码回退与数据回退是两件事：**先用「设置 → 导出」保存 JSON 快照**，再回退代码，必要时导入快照恢复数据。升级 → 降级 → 再升级的演练已写入验收测试（TC-09）。

## 八、已知边界

- 在线判题 / 代码提交、账号与多用户、云端同步、移动端不在范围内。
- 洛谷 / 力扣 / 蓝桥杯题库**不做自动抓取**，走手工录入或「会话式工作流」（我帮你搜题 → 产出符合附录 C 契约的结构化文件 → 项目导入）。
- 蓝桥杯大纲为按官方 PDF 整理的基线 YAML，每年由你手动更新；新增版本不影响旧版本题单。
- AI 输出一律标注「AI 生成，仅供参考」，且不自动写入正式题解；标签建议需人工确认后才参与组题。
- PDF 导出使用 reportlab 内置 CJK 字体，DOCX 使用 python-docx；两者均为可选依赖，缺失时界面给出安装提示。
