## 版本管理与回退约定

| 项 | 约定 |
| --- | --- |
| 分支 | `main` 只放可运行稳定版；日常开发在 `dev` |
| 标签 | 每完成一个里程碑打 tag（`v0.2.0-m1`、`v0.3.0-m2` …） |
| 提交 | Conventional Commits（`feat:` / `fix:` / `docs:` / `refactor:` / `chore:`），一事一提交 |
| 数据库 | schema 变更一律走 Alembic 迁移，可 upgrade / downgrade；数据文件不入库，另有每日备份与 JSON 快照 |
| 回退 | `git tag` → `git checkout <tag>` → `alembic downgrade <revision>`；需保留历史时用 `git revert <commit>`，避免对已提交历史 `reset --hard` |

常用命令：

```bash
git log --oneline --decorate --all   # 查看版本与标签
git tag                              # 列出可回退的稳定版本
git checkout v0.2.0-m1               # 回到某个里程碑版本验证
git revert <commit>                  # 撤销某次改动且保留历史
```
